样式变量

整套系统能用的颜色、字号梯度、间距、圆角与阴影，全部以变量定义，页面里不出现写死的色值。 语义层由原子色阶派生，业务代码只调语义层——换主题时改的是派生关系，不是逐页改颜色。 下面每一项都用该 token 的真实值渲染，点任意一项即可复制变量名。

字体

TYPOGRAPHY51

每行用该 token 的真实值渲染，按字号从小到大排列。右侧标注它是「字号」单值还是「完整简写」（含字重与行高）——单值 token 不能直接写进 CSS 的 font 简写，必须配字族才生效。

这一段原来只有变量名和数值，没有可看的东西。现在按类型拆开，每一类都用它自己的方式画出来。
