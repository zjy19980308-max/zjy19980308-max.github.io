SVG → 字体 tools / svg2font.py

线性图标不用 mask-image 贴 SVG，而是真正打进字体：一个脚本把整个目录的 SVG 变成 TTF、WOFF2、类名表和清单。以后新增图标只要把 SVG 丢进目录重跑，已有图标的码位保持不变。

python3 tools/svg2font.py <svg目录> lib/fonts --family CSES-Line --prefix cses-line- \
       --cats 分类.json --keep lib/fonts/cses-line.manifest.json
它做了什么。① 读每个 SVG 的路径；② 描边型的（stroke）先按线宽、线帽、拐角把描边扩成闭合轮廓，填充型的直接用；③ 按 viewBox 等比缩到 1000 单位、居中；④ 三次曲线转二次（TrueType 只收二次）；⑤ 分配私用区码位，合成字体，写出 CSS 与清单。
依赖：fontTools、skia-pathops（描边转轮廓）、brotli（woff2）。
这次的结果：815 个 SVG 全部转换成功，其中描边型 729 个、填充型 86 个；跳过 3 个（两个无名文件、一个自交轮廓）。
