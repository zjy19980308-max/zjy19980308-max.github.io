一条能走通的路线 照这个顺序点一遍，22 步不断

  1. 工作台看待办打开 →
  2. 待我处理点第一条的「去确认」打开 →
  3. 卡片悬浮鼠标停在卡上才出现驳回/通过试 →
  4. 审批记录点顶部锚点滚过去试 →
  5. 分支未定 ⋯看第二张单，悬浮省略号试 →
  6. 完整流程图点步进器打开试 →
  7. 发起申请整页挑单：三大类 + 分组打开 →
  8. 挑一张单点「付款申请」进表单试 →
  9. 填表提交改金额看审批链变化打开 →
  10. 换身份 → 流程后台头像切周宁，右上角出现入口试 →
  11. 后台工作台运行状态 + 需要你处理打开 →
  12. 流程管理未发布置顶、开关、切版本打开 →
  13. 流程配置 1·基础信息三选一，分组跟着变打开 →
  14. 流程配置 2·表单设计左控件库、右属性，都是悬浮窗打开 →
  15. 描述对话追问在输入框上方打开 →
  16. 生成流程草稿在下方确认，不在右下角试 →
  17. 流程配置连线悬浮出加号打开 →
  18. 提交体检修完 3 项才能提交审阅打开 →
  19. 变更审阅批准并发布打开 →
  20. 运行监控点那条「异常」打开 →
  21. 异常处理写依据后确认放行打开 →
  22. 版本与回退三步回退 → 复盘 → 进检查项库打开 →
